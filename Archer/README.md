# Archer's Work

This directory contains Archer's numerical reproductions and extensions of low-rank Vlasov-Poisson methods.

## [DLR reproduction](<DLR reproduction/>)

Fixed-rank K-S-L projector-splitting solvers for the Vlasov-Poisson equation. The folder contains two 1D1V tests, a direct 3D3V extension, the Einkemmer-Lubich reference paper, and phase-space/electric-field results.

## [Suppressing](Suppressing/)

Reproductions of external-electric-field control experiments. The implementations combine a semi-Lagrangian forward solver, a discrete adjoint, and gradient-based optimization. The two result folders contain beam-shaping comparisons and a controlled two-stream test.
