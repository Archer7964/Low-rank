# Experiment 2 Results: Two-Stream Control

These figures correspond to the symmetric two-stream problem in `../2-stream Instability.py`.

| File | Result shown |
| --- | --- |
| `Figure_1.png` | Compares the target equilibrium with the controlled distribution at T = 0, 20, and 40. The two velocity beams remain nearly homogeneous in space and visually close to the prescribed equilibrium through the final time. |
| `Figure_2.png` | Shows electric energy on a logarithmic scale. The energy drops sharply during the initial transient, then returns to a bounded oscillatory level with a modest late-time rise; suppression is therefore not monotone or complete. |

Together, the figures show good preservation of the target phase-space profile, while also recording residual electric activity that is difficult to see in the density plots alone. No uncontrolled baseline or numerical objective history is included in this folder, so the amount of improvement cannot be quantified from these PNG files by themselves.
